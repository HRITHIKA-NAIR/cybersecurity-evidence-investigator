# Cybersecurity Evidence Investigator

An AI-powered cybersecurity investigation application that analyses suspicious URLs, emails, and text by gathering evidence, assessing risk, and explaining its conclusions.

## Core Features

- Suspicious URL, email, and text investigation
- Cybersecurity indicator extraction
- Threat intelligence lookup
- AI-assisted evidence analysis
- Threat score and confidence assessment
- Counter-evidence and conclusion challenge
- Explainable investigation results

## Tech Stack

- React + Vite
- FastAPI
- Python
- Gemini API
- VirusTotal API
- LangGraph
- SQLite
